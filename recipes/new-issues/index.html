    BQL Credit Primary market

    New Issues¶

    BQL can see bonds that are announced but not yet priced, in line with SRCH <GO> and PREL <GO>. The universe covers deals that are announced and unpriced, or that priced within the last calendar day.

    Each deal's progress is in LATST_STATS_FOR_MOST_RECENT_DEAL:

    1. Mandate
    2. Guidance
    3. IPT
    4. New Deal

    Two switches are needed

    bondsUniv(INCLUDEPRELIMINARYSECURITIES='Y') adds preliminary securities to the universe, and PRELIMINARY_SECURITY=='Y' keeps only those. Without the filter you get the whole active bond universe.

    Data on this page

    The outputs below are live data as of 2026-11-17 and will differ when you run the queries.

    New AT1 / RT1 deals in USD, EUR, GBP¶

    INCLUDEPRELIMINARYSECURITIES, issuance_pricing, as #alias

    Bank AT1s and insurance RT1s currently in the pipeline, with deal status, marketed tenor and initial price talk.

    from polars_bloomberg import BQuery

query = """
for(filter(bondsUniv(INCLUDEPRELIMINARYSECURITIES='Y'),
        PRELIMINARY_SECURITY=='Y' and
        crncy() in ['USD', 'EUR', 'GBP'] and
        (basel_iii_designation() == 'Additional Tier 1' or
         solvency_ii_designation() == 'Restricted Tier 1')))
get(name, LATST_STATS_FOR_MOST_RECENT_DEAL, marketing_tenor,
    issuance_pricing as #IPT)
"""
with BQuery() as bq:
    df = bq.bql(query).combine(on="ID")
print(df)

    Notes

    • as #IPT renames a column without a let() block.
    • #IPT and PRICING_TYPE stay null until the deal reaches the IPT stage. Until the deal prices, the coupon in name is often a placeholder 0.
    • issuance_pricing returns two columns (the value and PRICING_TYPE), so the result holds four DataFrames, and combine(on="ID") joins them into one row per bond.

    New Technology deals in USD, EUR, GBP¶

    classification_name(BCLASS)

    The same screen by sector instead of capital tier, using Bloomberg's BCLASS classification at level 3.

    from polars_bloomberg import BQuery

query = """
for(filter(bondsUniv(INCLUDEPRELIMINARYSECURITIES='Y'),
        PRELIMINARY_SECURITY=='Y' and
        crncy() in ['USD', 'EUR', 'GBP'] and
        classification_name(classification_scheme=BCLASS,
                            classification_level=3) == 'Technology'))
get(name, LATST_STATS_FOR_MOST_RECENT_DEAL, marketing_tenor,
    issuance_pricing as #IPT,
    classification_name(classification_scheme=BCLASS,
                        classification_level=3) as #sector)
"""
with BQuery() as bq:
    df = bq.bql(query).combine(on="ID")
print(df)

    Watch out

    #IPT is in the unit that PRICING_TYPE names: Yield in percent, Floater Spread in basis points. Don't compare the numbers across rows without it.

    Notes

    • Without as #sector, the column is named after the whole classification_name(...) expression.
    • To screen another sector, change 'Technology' to another BCLASS level-3 name.

    Pipeline by currency¶

    count(group(...))

    How many deals are in the pipeline in each currency.

    from polars_bloomberg import BQuery

query = """
get(count(group(id, by=crncy())) as #n)
for(filter(bondsUniv(INCLUDEPRELIMINARYSECURITIES='Y'),
           PRELIMINARY_SECURITY=='Y'))
"""
with BQuery() as bq:
    df = bq.bql(query)[0]
print(df.select(currency="ID", deals="#n").sort("deals", descending=True).head(6))

    Notes

    • With group(...), the ID column holds the group key, not a security.
    • The result also has ORIG_IDS:* columns, which are filled only when a group has one member. The select() drops them.
